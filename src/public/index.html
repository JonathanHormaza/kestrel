PRODUCCIÓN

Rust Framework | Kestrel

Arquitectura modular de alto rendimiento con proxy inverso y Rate Limiter por IP.

🔍 Recorrido de Archivos

  • Rutas API: Configura endpoints REST en src/api/mod.rs.
  • Lógica de API: Define controladores e interfaces en src/api/ejemplo.rs.
  • Frontend / Vistas: Renderizado de estáticos en src/public/mod.rs.
  • Conexión Base de Datos: Inicialización de PostgreSQL en src/db.rs.
  • Orquestación: Configuración global y Middlewares en src/main.rs.

🛡️ Seguridad y Pruebas

  • Ataque de Rate Limit: Ejecuta peticiones consecutivas para probar el bloqueo por IP (Límite: 1 req/s, ráfaga de 5): 
    for i in {1..10}; do curl -i http://localhost/api/status; done
  • Fuzzing / 404: Comprueba el manejo seguro de recursos inexistentes: 
    curl -i http://localhost/ruta-inexistente

🗄️ Esquemas de Base de Datos (PostgreSQL)

Para agregar tablas (usuarios, roles, datos), crea un directorio de migraciones o ejecuta consultas SQL vía sqlx::query! en src/db.rs.

Ejemplo de estructura para la tabla de usuarios: 

CREATE TABLE IF NOT EXISTS users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
